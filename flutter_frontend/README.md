# Vibe Coding Companion (Flutter)

Interactive book reader about vibe coding, with engagement hooks:

- Rich chapter/section/block structure
- Quizzes + prompts + checklists + callouts
- Bookmarks + highlights (persisted locally)
- Streaks + daily reading goal (persisted locally)
- Daily challenge (deterministic per day)
- Achievements (first bookmark, highlight, quiz win, streaks)

## Run

From `flutter_frontend/`:

```bash
flutter pub get
flutter run
```
